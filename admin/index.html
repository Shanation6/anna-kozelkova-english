01 / Вход

Подключить GitHub

Не подключено

Для редактирования нужен персональный токен GitHub с доступом Contents: Read and write только к репозиторию Shanation6/anna-kozelkova-english. Токен хранится лишь в памяти этой вкладки до её закрытия.

Как создать токен
  1. Откройте настройки токенов GitHub.
  2. Выберите владельца аккаунта и доступ только к anna-kozelkova-english.
  3. В Repository permissions установите Contents → Read and write.
  4. Создайте токен и вставьте его в поле выше. Никому его не отправляйте.
