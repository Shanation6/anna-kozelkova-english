# Анна Козелкова — английский для жизни и важных разговоров

Публичная витрина преподавателя английского языка. Сайт построен на обычных HTML, CSS и JavaScript и размещается на GitHub Pages. Фотографии перенесены с исходной страницы [Taplink](https://taplink.cc/annette.english_) и лежат в `photos/`. Тексты и подписи можно редактировать в кабинете.

## Структура

- `index.html` — главная страница, направления обучения, результаты и контакты.
- `content/gallery.json` — рубрики, подписи и порядок фотографий.
- `photos/` — изображения галереи и основных блоков.
- `admin/` — кабинет управления галереей.

## Локальный просмотр

Запустите любой статический HTTP-сервер в корне репозитория, например `python -m http.server 4173`, затем откройте `http://localhost:4173/`. При открытии `index.html` через `file://` браузер может заблокировать загрузку JSON.

## Кабинет

Откройте `/admin/` на опубликованном сайте. Для записи нужен [fine-grained personal access token](https://github.com/settings/personal-access-tokens/new) GitHub, ограниченный репозиторием `Shanation6/anna-kozelkova-english` и разрешением **Contents: Read and write**. Токен вводится в форме и хранится только в памяти текущей вкладки. Он не входит в файлы сайта и не сохраняется в браузере.

Кабинет позволяет добавлять и удалять фотографии галереи, менять подписи, описания, рубрики, порядок и подборку «Главное». Фотографии, которые используются непосредственно в блоках главной страницы, закреплены и защищены от удаления через кабинет. Публикация создаёт один коммит GitHub, после чего GitHub Pages обновляет сайт.

## Публикация

В настройках репозитория выберите **Settings → Pages → Deploy from a branch → main / (root)**. В репозитории есть `.nojekyll`, чтобы Pages отдавал файлы без обработки Jekyll. Все пути к ресурсам относительные, поэтому сайт работает и по адресу проекта GitHub Pages.

## Примечания

Это демонстрационная версия для согласования дизайна и содержания. Контактные кнопки ведут в WhatsApp и ВКонтакте Анны. Кабинет управляет фотоархивом; для редактирования текста остальных разделов нужно изменить `index.html`.
